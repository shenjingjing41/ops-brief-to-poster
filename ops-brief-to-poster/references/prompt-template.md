# 生图提示词结构

将以下字段填为一个完整提示词，不能向模型传递未填的模板符号。只写本次相关要求，不累加历史版本中互相冲突的风格。

```text
用途：运营活动海报，直接输出完整图片。
画布：本次确定的比例、方向；如请求精确像素，在输出后核实。
受众与传播目标：从分析提取的受众、主利益和用户应看懂的行动。

布局：按阅读顺序列出每个区块、文案优先级、相对面积、素材位置及留白。
确保每个任务的条件、数字单位、奖励及获得方式在同一阅读单元内。

风格：根据 style-plan.md 合并用户指定风格与配色，以及补足后的字体、形状、素材表现、光影和装饰规则；用户要求优先于默认风格文件，只保留一个无冲突方案。
不要仅以“高级、好看、精美”等泛词代替具体要求。

若为保持布局换风格：明确编辑目标、不可改变的文案/换行/区块/商品，以及允许改变的视觉属性，不重新规划布局。

上图文案：按区块逐条列出最终文案，要求准确保留；不添加未提供的运营事实。
任何新文案必须在工作记录中标出授权来源。

输入图片：逐一说明是风格参考、商品外观参考，还是需原样使用的正式素材。
缺素材处理：写清哪些区域留白，不把占位标签画出来。不伪造 logo、二维码和正式封面。

避免：本次相关的错误机制和视觉失败项。
输出：一张平面的完整海报图，无场景样机、尺寸标注、说明文字或 HTML。
```

## 生成后逐项检查

1. 事实：标题、日期、数字单位、奖品名、限制是否与锁定文案一致。
2. 逻辑：抽奖没有变必得；当天没有变累计；任务与奖励没有错配。
3. 可读性：手机浏览时关键条件清楚，没有裁切、错字或叠字。
4. 风格：用户指定的配色、主要风格特征和强度得到执行，信息载体与背景有区分；保持布局换风格时另检查结构漂移。
5. 素材：无伪造标识/书封，无虚假二维码；参考图没有被误当作要照搬的整图。

检查发现问题要明确记录为待修正项，而不是默认“可发布”。
