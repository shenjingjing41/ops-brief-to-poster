# 临床决策默认风格：冷紫偏蓝、柔和色域背景、轻薄信息结构

配置 ID：`clinical-default`，版本 v8。本skill默认用于线上运营海报、一般品牌传播及线下会议展位、背景板、易拉宝、单页等。线上线下共用同一视觉语言，渠道只影响尺寸、信息密度、阅读距离和布局。用户本次明确的风格、配色、布局和素材处理要求优先覆盖对应默认。本配置是基于参考图形成的设计配置，不是官方品牌规范，也不保证一次生成即可精确复现。

- [临床决策传播任务示例](clinical-examples.md)及其参考图只用于理解产品介绍、扫码页、专科演示和展架的信息关系，不继承其中的业务内容、Logo落位、标题特效、灰底、物料标签或展示环境。
- 参考图同时包含平面排版、渐变光影、手机轻透视、商品摄影和立体IP。可合理推断的共同方向是清透亲切的医学AI品牌视觉；正式色值、字体、Logo安全区和全部IP姿态仍未确认。不得复制参考图中的日期、二维码、功能、医学内容或其他事实。

## 不可违背的默认视觉规则

### 配色与背景

- **冷紫偏蓝。** 紫色承担品牌识别，避免粉紫、玫红和偏暖兰花紫；不能被纯蓝或蓝绿主调替代。冷紫 `#6545F5`、蓝紫 `#5865F2`、浅紫 `#E3E2FC`、`#DCDDFC` 仅是参考起点，不是官方色值，也不是要求模型精确复现的硬约束。
- **近白阅读区 + 边角色域。** 以近白和极浅冷紫保持内容清晰，边缘或角落形成几团大范围浅紫色域，外围只加入少量冰蓝、淡青；不做整页均匀铺紫，也不把亮区洗成纯白。色域位置随构图调整，不固定左右渐变。
- **低频、低对比层次。** 使用大跨度柔和渐变、宽幅柔光和局部提亮；高饱和紫只用于标题、图标、标签等重点，不默认铺满背景。
- **轻量纹理。** 主要质感来自渐变、透明叠色和软阴影。按需使用少量超大、宽缓、延伸出画布的半透明弧面或稀疏边缘方块；不默认使用颗粒、纸纹、密集网格、硬边波浪、厚重布料或舞台结构。
- 背景必须比信息载体和主体更柔、更淡；不叠加扫光、强光束、速度线、交叉光带、发光环轨、复杂星空或密集纹理。

### 字体与信息结构

- 标题做适度字体设计，通过字形比例、字距、字重、笔端和语义换行建立辨识；短标题可适度倾斜，长标题和正文优先稳定易读。不损伤字形、不增减笔画、不改变文案。
- 基础文字用深灰或深紫，关键词可用冷紫强调，局部渐变末端可带少量蓝青；不把所有文字做成渐变。避免发光描边、强高光、厚重立体挤出、尖刺、刀锋切角和夸张拉尾。
- 信息载体采用近白到浅紫的轻薄圆角面板、细白边和克制软阴影，与背景保持可辨色差；可以使用冰蓝局部反光，但不机械地每句话一个白卡。
- 图标使用简洁线性或实心几何样式，数量由真实内容决定；不得冒充正式 Logo、产品 UI 或奖品。

### 主视觉与空间感

- 新生成配图默认参考 [轻量功能插画](functional-illustration.md)：薄面板、柔和渐变与阴影、有限叠层和轻透视，用画面解释已确认的内容；它不是正式产品 UI，不凭空增加能力。是否加入配图由内容决定。
- 信息优先，装饰让位。第一焦点由传播任务决定，可以是标题、真实商品、产品演示或扫码入口；先保障标题、核心利益、参与条件和奖励的字号、空间与可读性。
- 文案短且空间充足时可采用图文结合；文案长或信息密集时优先减少或删除装饰图，仅保留低对比柔光、细弧线等点缀。不得为礼盒、展台、手机、IP或其他装饰缩小关键文案。
- 需要图文并置时，先安排文字空间，再决定图片比例和位置。图片抢占文字时缩小或删除图片，不套固定百分比；删图后重新平衡标题对齐、文字宽度、留白和区块衔接。
- 区分装饰图与信息图：氛围礼盒、托盘、展台可删减；真实商品图、有来源的产品 UI 和正式 IP 按传播需要保留，并紧邻对应说明。缺少真实 UI 时可用文字、几何关系或说明性插画，不冒充正式 UI、不编造循证内容或书封。
- 允许适度渐变、薄阴影、轻透视和既有立体 IP；大面积信息结构保持轻薄，不做厚玻璃、金属机器或重 3D 展台。氛围来自配色、柔光、材质、细线和有限空间层次，不靠堆积元素。默认不加星芒；若需层次只用不发光的细弧线。

## 按渠道适配

以下是同一风格的布局适配，不是固定模板；模块数量和比例服从内容。保持布局换风格时沿用锁定结构，不按本表重排。

| 物料 | 适配重点 |
|---|---|
| 线上 | 先传达核心主张，再解释条件和行动；未指定竖版默认 9:16，并按手机展示大小检查层级。 |
| 展位／横向背景板 | 集中品牌与主利益，确认实物尺寸、分板、接缝和遮挡；Logo与标题避开接缝。 |
| 易拉宝 | 远处读懂标题与核心价值，近处理解说明和入口；确认实物尺寸与底部遮挡区。 |
| 宣传单页 | 按真实内容分组；长医学文字和参考文献需正式排版，生图预览不替代小字校对。 |
| 手举牌／小型标牌 | 保留一个主要信息，按实际尺寸、刀模和手柄区域减少细节。 |

产品功能主推时使用有来源的 UI 或文字结构；礼品主推时集中展示真实商品，并将条件与奖励邻近组织。不因渠道新增 IP、手机、礼盒、功能、价格或承诺。线下确认尺寸或供应商模板后再制作，出血、色彩模式、刀模和分板缺项时标明限制，不把 AI 预览称为印刷完稿。

## 正式品牌资产与缺素材

线上线下统一读取 [正式素材规则](clinical-offline-assets.md)。默认右上角小尺寸横排双 Logo，从左到右为丁香园、临床决策；保留外边距、组内间距和原始比例，不抢标题。浅色背景用正式彩色 PNG，深色背景按对比度选正式白色 PNG；优先原样贴入，不重绘、改色、拉伸或加特效。无法可靠合成时保留同位置净空，并明确待贴入，不伪造或无声省略。用户本次明确要求可覆盖默认位置。

IP 仅按需使用；三视图只作身份、比例、颜色和外观参考，不将整张参考板或方向标签带入成品，默认不擅自修改服装、表情和四瓣配件。二维码必须原样贴入或留净空，不能重绘。缺正式封面、商品、Logo或二维码时用文字表达或留白，不把占位说明印在海报上。

## 风格提示词种子

以下段落用于合并到本次完整生图提示词；它是默认风格的执行种子，不替代本次任务的尺寸、布局、文案、素材角色和传播目标：

> 临床决策品牌物料，采用偏蓝冷紫、近白阅读区和边角浅紫色域，少量冰蓝淡青辅助；背景低对比、宽幅柔光、软阴影和少量宽缓曲面，信息载体轻薄，内容区清晰明亮。标题做适度字形与排版设计，正文稳定易读。信息优先，主视觉和装饰服从传播任务；长文案时减少或删除装饰图。避免粉紫、玫红、纯蓝绿满版、密集底纹、扫光、光轨、厚玻璃、重3D、虚构UI、虚构Logo、虚构二维码及新增业务承诺。尺寸、布局、文案和素材角色以本次任务为准。

## 默认风格核对

生成前后按 [设计师自检](design-review.md) 完成整体检查，并补查：

1. 紫色是否仍偏冷、偏蓝，且没有被纯蓝或蓝绿取代？
2. 内容区是否有近白亮度、足够文字对比和清楚的信息载体？
3. 第一焦点是否服务本次传播目标，是否为装饰挤小关键文案？
4. 长文案是否减少了装饰，删图后构图是否重新平衡？
5. Logo、IP、商品、UI和二维码是否按正式素材规则处理？
6. 是否改变日期、数字、单位、当天／连续／累计、抽奖／必得等条件与奖励关系，或新增产品能力和承诺？

保持布局时只更新用户允许改变的视觉属性；线下预览不冒充生产文件。
