# 需求补全与选择题

## 目标与判断顺序

让运营用一句话、零散要点、文档或参考图片启动，不要求先准备专业 brief。先读当前请求、相关对话和附件，再只补真正影响业务正确性、投放规格与传播方向的信息。以前活动的奖励、日期和尺寸不能填进新活动；既有品牌风格和正式素材可以按适用范围复用。

在工作记录中将信息分为：有来源的事实、用户本轮选择、可采用的设计默认、仍需用户回答的缺项、不适用。不是每个字段都必须提问或上图。

| 检查项 | 何时需要询问 | 可采用的处理 |
|---|---|---|
| 业务与品牌 | 无法确认品牌且品牌身份影响这张物料 | 根据相关文案、Logo或用户说明识别；中性概念图可不指定品牌，不因历史一直做临床决策就猜品牌 |
| 用途、物料与规格 | 无法区分线上/线下或交付形式；线下缺实物尺寸 | 泛指线上竖版可说明采用9:16；线下先问尺寸，用户明确只需不定尺寸概念稿时可推荐比例并标为概念预览 |
| 受众 | 不同受众会显著改变表述、阅读距离或信息密度，且没有上下文依据 | “新人医生”等已在文档中明确时不再问；不要从传播受众推定领取资格 |
| 传播目标、首要卖点 | 内容存在多个竞争重点，或连活动目的也未说明 | 可让用户选领福利、报名、体验功能、了解品牌；已有明确主利益时直接据此规划 |
| 文案与业务规则 | 没有足够活动内容，或资格、时间、价格、数量、单位、抽奖/必得等影响含义的事实不清楚 | 问缺失的实际规则；已有文案默认保留。用户选择“帮我写文案”只授权表达创作，不授权编造活动规则或医疗效果 |
| 行动与入口 | 以报名、领取等转化为目标，参与方式不清楚 | 询问扫码、App内、现场等；纯品牌传播可不设入口。已知扫码但缺码，可留空继续预览，不伪造二维码 |
| 必用素材与锁定项 | 明确必须展示的商品、IP或原图锁定要求尚不明确，影响构图 | 先检查已提供和内置可用素材，不重复索取；缺正式封面、Logo、二维码时留净空或用文字表达，不编造 |

字体、字号、圆角、阴影、色值、材质、留白、卡片数量和具体排版由设计师自行判断，不要求运营选择构图、评价专业方案或编写生图提示词。未指定风格按业务默认路由，不为选择风格阻塞任务；主题要求和参考图优先。仅在用户主动要求视觉选项时提供适合本次的选择，不默认增加风格确认。

业务取舍与设计选择分开：目标不清时可以问“优先拉新还是促进老用户参与”，而不是问“奖品占画面几成”。若执行原要求会削弱传播目标，指出具体原因并给出处理建议；已明确的视觉方向不因个人偏好擅自覆盖，涉及改文案或规则的建议先取得必要授权。

## 如何提问

- 每轮最多三个问题，允许更少。优先解决业务矛盾和用途，再问依赖前一答案的尺寸、规则或素材。不要为凑足三个问题而追问。
- 用运营语言，一题解决一个决定，给二至三个与当前任务相关的选项；存在依据时标记推荐项，支持用户自定义回答，不强迫落入预设分类。日期、实物尺寸和真实规则直接收集准确文本，不能用随意选项诱导事实。
- 有可用的选择题交互工具且适合当前问题时使用；否则在回复中列出简短编号选项，让用户按“1A、2B”或自然语言回答。需要答案才能推进时明确提出问题并等待，不在进度说明中埋入问题。
- 用户给出答案后只补仍阻塞任务的缺项，保留本次已回答选择。必要事实未答不擅自补；能独立完成的提取和分析可先做，不消耗生图生成一张事实不明的正式活动图。

## 模糊请求的示例

用户仅说：“做一张临床决策活动海报。”品牌已知，不再问业务。首轮可以问：

1. 主要用在哪里？A 手机社群传播；B 公众号长图；C 线下展会。
2. 最希望用户做什么？A 领取福利；B 报名参加活动；C 体验产品功能。
3. 文案准备到哪一步？A 已有文案或文档，按原文；B 我提供活动要点，请帮我写；C 先做视觉概念，实际内容待补。

这不是固定问卷。例如用户已说“80×200cm易拉宝、突出礼品”，只问缺少的活动内容或入口。选线下后才收集实际尺寸；选领福利后检查领奖规则。用户选择概念稿时，可用已知文字或不含未知事实的视觉结构，缺失字段留在记录里，不把“待定”等内部标签印上图；确需模拟日期和礼品时先取得模拟授权。

## 停问与执行

- **足够执行：** 主体、用途规格、传播主线和必要文案规则已清楚，余项可默认或可留空。简短说明执行方案后继续，不再询问“是否开始生图”。
- **必须等待：** 同一奖励同时写抽奖和必得，关键价格或单位矛盾，或无活动内容且未授权创作文案/概念稿。问清对应问题，不靠小字掩盖。
- **可以预览：** 仅缺二维码、正式书封、定制商品图等，已有允许的留空或文字表达方式。说明预览限制，继续完成用户要求；不称为发布完稿。

执行说明例：“临床决策｜社群竖版9:16；突出30天会员福利，规则按文档保留。采用默认清透紫蓝风格，二维码留空待贴入。”说明中的数字只能来自本次来源，不能机械复制示例。

## 维护时检查的代表情境

1. **完整文档：** 《新人提问活动》已给出受众、福利、规则、日期和二维码，用户要求默认风格。预期直接执行；缺会员卡和书封用文字表达，不重新询问风格、受众或主卖点。
2. **一句话需求：** “做一张临床决策活动海报。”预期先问用途、传播目标和内容准备情况，不立即编造活动并生图。
3. **业务矛盾：** “提问3次即可抽奖，参与者必得帆布包。”预期核实抽奖和必得的关系；不擅自选一种，不用默认风格问题转移焦点。
4. **只缺视觉细节：** 文案、规则、用途齐全，未指定颜色和排版。预期使用品牌默认直接生成，不让用户选择圆角、阴影或模块数。
5. **只缺素材：** 报名规则齐全但没二维码。预期留净空做预览，不生成假码，不让素材缺失阻塞整个方案。

这些是人工检查情境，不代表已进行独立执行测试；若实际行为过度提问或漏问，再依据具体失败修订。
